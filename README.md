Audi Dealership – Descriere Generala
Acest proiect este o aplicatie Django care reprezinta un magazin online dedicat unui dealership
Audi.
Aplicatia gestioneaza produse auto precum modele, versiuni, accesorii si oferte.
Utilizatorii pot vedea produsele, pot citi detalii si pot interactiona cu continutul.
Aplicatia functioneaza pe baza unui sistem de modele definite in Django.
Fiecare model reprezinta un element al magazinului: produse, categorii, recenzii sau comenzi.
Acestea sunt stocate intr-o baza de date relationala.
Partea vizuala este generata prin sabloane HTML, iar logica este asigurata de view-uri Django care
preiau datele din baza si le afiseaza in paginile aplicatiei.
Utilizatorii isi pot crea cont, se pot autentifica si pot plasa comenzi.
Aplicatia include si un sistem de recenzii in care utilizatorii pot lasa comentarii la produse.
Exista si o zona de administrare oferita de Django Admin, unde se pot adauga sau modifica
produse, oferte,
categorii si alte informatii necesare functionarii magazinului.
Scopul proiectului este de a demonstra modul in care pot fi combinate structurile Django
(baza de date, sabloane, view-uri si formulare) pentru a crea o aplicatie web functionala si usor de
extins.
